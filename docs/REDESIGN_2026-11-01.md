# Editorial portfolio redesign — 1 November 2026

## Result

The work index now appears immediately after the introduction. A warm off-white/cobalt visual identity, serif accents, fine rules, a more focused owner-provided portrait, and eight original project covers replace the previous glass/bento presentation. Dark mode, core content without JavaScript, contact destinations, and GA4 configuration are retained.

NGA Inventra adds an eighth case study grounded in its public backend, UI, migration, and test sources. Publisher copy reflects its digital-library scope and the default-disabled legacy financial features. Private repositories remain excluded.

The work index supports combined category/search filtering, accessible result announcements, empty-result reset, and grid/list presentation. The header and heading counts derive from the project data. Each case study includes implementation context, evidence links, next steps, and next-project navigation. All artwork is explicitly labeled as an illustrative concept.

The static export command is opt-in and does not change the normal Next.js hosting mode. It makes the same portfolio available for a private review deployment.
