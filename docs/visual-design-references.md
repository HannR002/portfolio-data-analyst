# Portfolio design research — 1 November 2026

This redesign is an original composition informed by current live portfolios, not a reproduction of their code, artwork, or personal content.

| Reference | Observed pattern | Application here |
| --- | --- | --- |
| [Olivier Larose — Folio 2026](https://www.olivierlarose.com/) | A type-led introduction and a structured project index with clear scope descriptions. | Oversized editorial typography, restrained colors, and a grid/list switch for the work index. |
| [Brittany Chiang](https://brittanychiang.com/) | Direct professional positioning, readable project descriptions, technology context, and accessible navigation. | Clear identity, actual source links, explicit project stages, keyboard navigation, and substantive case studies. |
| [Dennis Snellenberg](https://www.dennissnellenberg.com/) | Prominent personal identity, location, selected work, and a direct contact invitation. | Owner-provided portrait, Jambi location, project-led structure, and visible email/WhatsApp/GitHub links. |
| [Bruno Simon](https://bruno-simon.com/) | A distinctive explorable 3D world with controls and quality options. | Small optional portrait interactions with keyboard buttons and reduced-motion support. The work remains directly accessible. |
| [Awwwards portfolio gallery](https://www.awwwards.com/websites/portfolio/) | A current discovery source for varied portfolio directions. | Broad reference for composition and visual variety; no award claim is made for this portfolio. |

## Direction

Warm off-white and cobalt blue, fine rules, large sans-serif headings paired with italic serif accents, an existing portrait, and eight distinct project illustrations. Dark mode respects the visitor's system preference and explicit choice.

The gallery precedes the biography. Each project connects a short description to its tools, editorial stage, case study, and public source evidence. NGA Inventra is added; P4I Publisher's description now reflects its digital-library scope and default-disabled legacy financial features.

## Content integrity

No client logos, testimonials, adoption counts, employment history, revenue, scientific validation, or production results were invented. All cover art is original HTML/CSS/SVG, labeled as an illustrative concept rather than a product screenshot. Private repositories are omitted. Existing email, WhatsApp, GitHub, and GA4 configuration are retained.
